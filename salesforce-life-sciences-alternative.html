HCP segmentation without a Salesforce implementation

Salesforce Life Sciences Cloud (and Health Cloud before it) is a powerful platform when you have the licenses, the admins and the implementation roadmap. If what’s actually blocking you is “we have HCP lists in spreadsheets and we need scored, compliant audiences”, a platform project is the slow way there. LiteHCP Targeter is the fast way: one self-hosted PHP file that does exactly that slice.

Use LiteHCP Targeter for

Going from spreadsheets to scored, suppression-checked audiences and CSV exports this week, on hosting you already have.

Keep Salesforce for

Journeys, flows and connected clouds, call planning, consent orchestration and a certified vendor stack.

The platform-tax problem

Spreadsheet-to-audience workflows on an enterprise platform typically need licenses for everyone who touches the data, a data model, an integration or manual load path, and an admin to maintain it. For a focused targeting workflow you end up paying platform overhead for what is, functionally, import → rules → filter → export.

What the slice looks like in LiteHCP

  1. import

    Upload any CSV. Columns are matched for you (NPI, First name, Email opt-in and similar), every row is checked first, and you choose how gaps are filled. Profiles upsert by HCP ID, so re-imports are safe and keep the columns a file doesn’t have.

  2. score

    Every HCP gets a priority score (consent, recency and engagement; weights configurable), a tier and decile, and a 0–100 data-confidence score. Each profile explains its score.

  3. enrich

    When/Then rules set personas, tags and “cleared to contact” in run order. Test a draft on all HCPs and see what would change before you save.

  4. audience

    Build audiences in plain language with live counts: specialty, region, tier, reachability, data confidence, tags, custom fields. Do Not Contact HCPs are excluded automatically, with no override.

  5. export

    A minimal CSV by default, a CRM target list with tiers and planned calls, or an email-platform list that needs an admin, the PII setting and email consent, and is audited.

Total setup: three steps

  1. Upload one filePut litehcp.php on any PHP 8 host. The SQLite database creates itself.
  2. RegisterThe first account becomes the admin. No email server or API keys needed.
  3. Load the sample200 scored HCPs, 9 enrichment rules and 6 audiences, ready to explore.

Your own CSVs import the same way: columns are matched for you and every row is checked before anything is written. Deployment guide

When Salesforce is still the answer

  • You already run Salesforce and your HCP engagement lives in journeys, flows and connected clouds.
  • You need call planning, case management, consent orchestration or omnichannel execution in one validated platform.
  • Your compliance organization requires a certified vendor stack with formal SLAs.

LiteHCP exports plain CSVs precisely so it can sit alongside platforms like Salesforce: build the audience here, run the campaign wherever you already work.
